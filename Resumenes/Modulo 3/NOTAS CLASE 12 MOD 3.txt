CDP / LLDP:

CDP: DESCUBRIMIENTO DE VECINOS CISCO.
LLDP: ESTANDAR IEEE 802.1AB.
SHOW CDP NEIGHBORS DETAIL
SHOW LLDP NEIGHBORS DETAIL
VECINO DE CAPA 2 NO GARANTIZA CONECTIVIDAD IP.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

NTP:

SINCRONIZA RELOJES / UDP 123.
NTP SERVER 192.168.100.10
SHOW CLOCK
SHOW NTP ASSOCIATIONS
SHOW NTP STATUS
STRATUM: DISTANCIA A LA REFERENCIA, NO ZONA HORARIA.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

SNMP:

MANAGER NMS / AGENTE / MIB / OID.
GET CONSULTA / SET MODIFICA SI ESTA AUTORIZADO.
TRAP: NOTIFICACION SIN CONFIRMACION PROPIA.
INFORM: NOTIFICACION CONFIRMADA.
UDP 161 CONSULTAS / UDP 162 NOTIFICACIONES.
V1 Y V2C: COMUNIDADES, SIN CIFRADO.
V3: NOAUTHNOPRIV / AUTHNOPRIV / AUTHPRIV.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

SYSLOG:

0 EMERGENCIES / 1 ALERTS / 2 CRITICAL / 3 ERRORS.
4 WARNINGS / 5 NOTIFICATIONS / 6 INFORMATIONAL / 7 DEBUGGING.
MENOR NUMERO = MAYOR GRAVEDAD.
LOGGING HOST 192.168.100.10
LOGGING TRAP WARNINGS
SHOW LOGGING
UMBRAL WARNINGS INCLUYE NIVELES 0 A 4.

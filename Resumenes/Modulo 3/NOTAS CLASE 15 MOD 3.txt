FORMATOS:

JSON: OBJETO {} / ARREGLO [] / CLAVES CON COMILLAS DOBLES.
TIPOS: STRING / NUMBER / BOOLEAN / NULL / OBJECT / ARRAY.
TRUE, FALSE Y NULL EN JSON SE ESCRIBEN EN MINUSCULA.
YAML: ESTRUCTURA POR INDENTACION.
XML: ETIQUETAS.
YANG: MODELO DE DATOS, NO ES YAML.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

REST / HTTP:

GET LEE / POST CREA O EJECUTA OPERACION.
PUT REEMPLAZA / PATCH MODIFICA PARTE / DELETE ELIMINA.
200 OK / 201 CREADO / 202 ACEPTADO PENDIENTE / 204 SIN CUERPO.
400 SOLICITUD INVALIDA / 401 CREDENCIALES / 403 PROHIBIDO.
404 NO ENCONTRADO / 429 LIMITE / 500 ERROR DEL SERVIDOR.
ACCEPT: FORMATO ACEPTADO / CONTENT-TYPE: FORMATO DEL CUERPO.

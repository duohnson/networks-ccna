PRACTICA NAT:

CONFIGURAR OSPF:

R1
ROUTER OSPF 10
NETWORK 192.168.10.0 0.0.0.255 AREA 0
NETWORK 192.168.11.0 0.0.0.255 AREA 0
NETWORK 10.0.0.0 0.0.0.3 AREA 0
PASSIVE-INTERFACE FAST0/0
PASSIVE-INTERFACE FAST0/1
EXIT

R2
ROUTER OSPF 10
NETWORK 172.16.0.0 0.0.0.255 AREA 0
NETWORK 10.0.0.0 0.0.0.3 AREA 0
PASSIVE-INTERFACE FAST0/0
PASSIVE-INTERFACE SER0/0/1
EXIT

CONFIGURAR RUTA POR DEFECTO:

R2 (BORDE)
IP ROUTE 0.0.0.0 0.0.0.0 SER0/0/1

REDISTRIBUIR EN OSPF:
ROUTER OSPF 10
DEFAULT-INFORMATION ORIGINATE
EXIT

NAT ESTATICO:
TRADUCE DE 1 PRIVADA A 1 PUBLICA

SINTAXIS:			PRIVADA		PUBLICA
IP NAT INSIDE SOURCE STATIC (LOCAL INTERNA) (GLOBAL INTERNA))

EJEMPLO:
IP NAT INSIDE SOURCE STATIC 172.16.0.254 209.165.200.254

APLICACION EN INTERFACES:
INTER FAST0/0
IP NAT INSIDE
EXIT
INTER SER0/0/1
IP NAT OUTSIDE
EXIT

VERIFICAR:
DEBUG IP NAT 

CONFIGURAR EN EL ISP LA RUTA DE VUELTA:

ISP:
IP ROUTE 209.165.200.254 255.255.255.255 SER0/0/0

NAT DINAMICO:

1 PASO: CONFIGURAR UN POOL CON LAS PUBLICAS:

SINTAXIS:
	IP NAT POOL (NOMBRE) (1° UTILIZABLE) (ULT UTILIZABLE) NETMASK (MASCARA)

EJEMPLO:
	IP NAT POOL CCNA 209.165.200.241 209.165.200.246 NETMASK 255.255.255.248

-------------------------------------------------------------------------------------
2 PASO: CONFIGURAR UNA ACL PARA ESPECIFICAR LAS PRIVADAS QUE SE VAN A TRADUCIR:

STANDARD NUMERADA:
ACCESS-LIST 1 PERMIT 192.168.10.0 0.0.0.255
ACCESS-LIST 1 PERMIT 192.168.11.0 0.0.0.255

EXTENDIDA NUMERADA:
ACCESS-LIST 110 PERMIT IP 192.168.10.0 0.0.0.255 ANY 
ACCESS-LIST 110 PERMIT IP 192.168.11.0 0.0.0.255 ANY 

STANDARD NOMBRADA:
IP ACCESS-LIST STANDARD ACL
PERMIT 192.168.10.0 0.0.0.255
PERMIT 192.168.11.0 0.0.0.255
EXIT

EXTENDIDA NOMBRADA:
IP ACCESS-LIST EXTENDED ACL
PERMIT IP 192.168.10.0 0.0.0.255 ANY
PERMIT IP 192.168.11.0 0.0.0.255 ANY
EXIT

--------------------------------------------------------------------------------------
3 PASO: CREAR EL ENLACE ENTRE EL POOL Y LA ACL

SINTAXIS:
	IP NAT INSIDE SOURCE LIST (#/NOMBRE) POOL (NOMBRE)

EJEMPLO:
	IP NAT INSIDE SOURCE LIST 1 POOL CCNA

--------------------------------------------------------------------------------------

4 PASO: APLICARLO EN LAS INTERFACES:

INTER SER0/0/0
IP NAT INSIDE
EXIT
INTER SER0/0/1
IP NAT OUSIDE
EXIT

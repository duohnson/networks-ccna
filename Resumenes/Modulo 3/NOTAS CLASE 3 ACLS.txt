2. APLICAR LA ACL

STANDARD : SE APLICAN LO MAS CERCA AL DESTINO POSIBLE
EXTENDIDA: SE APLICAN LO MAS CERCA AL ORIGEN POSIBLE

SINTAXIS:
	INTERFACE (TIPO) (NUMERO)
	IP ACCESS-GROUP (#/NOMBRE) (IN/OUT)
	EXIT

EJEMPLO ESTANDAR:

R3
ACCESS-LIST 1 PERMIT 192.168.0.0 0.0.0.255
ACCESS-LIST 1 DENY ANY 		(IMPLICITO)

INTER FAST0/0
IP ACCESS-GROUP 1 OUT
EXIT

SPOILER DEL EXAMEN:

1. DENIEGUE QUE LA RED A VEA PAGINAS WEB, PERMITA EL RESTO DEL TRAFICO.

PASO 1: HACER DESGLOCE:
ORIGEN : RED A: 192.168.0.0 0.0.0.255
DESTINO: ANY 
PROTOCOLO: TCP
PUERTO : 80 443

PASO 2: CREAR LA ACL:  EXTENDIDA / NOMBRADA / PERRITO

IP ACCESS-LIST EXTENDED PERRITO
DENY TCP 192.168.0.0. 0.0.0.255 ANY EQ 80
DENY TCP 192.168.0.0. 0.0.0.255 ANY EQ 443
PERMIT IP ANY ANY
DENY IP ANY ANY
EXIT

PASO 3: APLICARLA:
R1
INTER FAST0/0
IP ACCESS-GROUP PERRITO IN
EXIT

2. PERMITA QUE LA RED A VEA PAGINAS WEB, DENIGUE EL RESTO DEL TRAFICO.

PASO 1: HACER DESGLOCE:
ORIGEN : RED A: 192.168.0.0 0.0.0.255
DESTINO: ANY 
PROTOCOLO: TCP				TCP /UDP	UDP		
PUERTO : 80HTTP 443HTTPS 		53 DNS		67/68 DHCP

PASO 2: CREAR LA ACL:  EXTENDIDA / NOMBRADA / PERRITO2

IP ACCESS-LIST EXTENDED PERRITO2
PERMIT UDP ANY ANY EQ 67
PERMIT UDP ANY ANY EQ 68
PERMIT TCP 192.168.0.0. 0.0.0.255 ANY EQ 80
PERMIT TCP 192.168.0.0. 0.0.0.255 ANY EQ 443
PERMIT TCP 192.168.0.0. 0.0.0.255 ANY EQ 53
PERMIT UDP 192.168.0.0. 0.0.0.255 ANY EQ 53
DENY IP ANY ANY
EXIT

PASO 3: APLICARLA:
R1
INTER FAST0/0
IP ACCESS-GROUP PERRITO2 IN
EXIT

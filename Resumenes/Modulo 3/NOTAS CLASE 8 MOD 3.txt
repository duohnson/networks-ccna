DHCP RELAY EN CADA VLAN REMOTA:
IP HELPER-ADDRESS 172.16.30.10

REDISTRIBUCION EN R1, DESDE CONFIGURACION GLOBAL:

ROUTER EIGRP 10
REDISTRIBUTE OSPF 1 MATCH INTERNAL EXTERNAL 1 EXTERNAL 2 METRIC 10000 100 255 1 1500
EXIT
ROUTER OSPF 1
REDISTRIBUTE EIGRP 10 SUBNETS
EXIT

R2 USA AS 20 Y R3 AS 30.
MATCH INCLUYE RUTAS EXTERNAS DE LAS OTRAS SUCURSALES; REVISAR SOPORTE EN IOS.
METRICA: ANCHO DE BANDA / RETARDO / CONFIABILIDAD / CARGA / MTU.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

R3:
IP ROUTE 0.0.0.0 0.0.0.0 200.0.0.2
ROUTER OSPF 1
DEFAULT-INFORMATION ORIGINATE
EXIT
ROUTER EIGRP 30
REDISTRIBUTE STATIC METRIC 10000 100 255 1 1500
EXIT

NAT:
ACL REDES-NAT: PERMITE LAS NUEVE REDES VLAN.
POOL PUBLICAS: 209.165.200.1 A 209.165.200.6 /29.

INSIDE: S0/0/0.31 / S0/0/0.32 / S0/0/1.
OUTSIDE: S0/1/0.

ISP:
IP ROUTE 209.165.200.0 255.255.255.248 200.0.0.1

ACLS:
VLAN10-SIN-WEB: DENY TCP 80 Y 443 / DENY UDP 443 / PERMIT RESTO.
APLICAR EN R4 FA0/0.10 IN.

VLAN50-LIMITADA: PERMITIR DHCP / DNS AUTORIZADO / WEB / ICMP ECHO-REPLY.
DENEGAR EL RESTO. APLICAR EN R5 FA0/0.50 IN.

VTY: ACL 80 PERMITE SOLO 172.16.80.0/24.
APLICAR ACCESS-CLASS 80 IN EN TODAS LAS VTY QUE SE USEN, EN CADA EQUIPO.

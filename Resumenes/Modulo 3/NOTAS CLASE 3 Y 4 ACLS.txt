BONUS: ACLS EN IPV6:
	1. SOLO HAY NOMBRADAS Y SOLO EXTENDIDAS.
	2. SE APLICAN CON EL COMANDO "IPV6 TRAFFIC-FILTER (NOMBRE) (IN/OUT)
	3. SE AGREGAN 2 SENTENCIAS ADICIONALES IMPLICITAS:
		PERMIT ICMP ANY ANY ND-NA
		PERMIT ICMP ANY ANY ND-NS
	4. NO SE USAN WILDCART SOLO SE TRABAJA CON PREFIX.

SINTAXIS:
	IPV6 ACCESS-LIST (NOMBRE)
	CONDICION PROTOCOLO ORIGEN/PREFIX DESTINO/PREFIX EQ PUERTO
	EXIT

EJEMPLO:
	IPV6 ACCESS-LIST KEN
	PERMIT TCP 2001:DB8:ACAD:1::/64 ANY EQ 80
	PERMIT ICMP ANY ANY ND-NA	(IMPLICITO)
	PERMIT ICMP ANY ANY ND-NS	(IMPLICITO)
	DENY IPV6 ANY ANY		(MPLICITO)
	EXIT

	INTER FAST0/0
	IPV6 TRAFFIC-FILTER KEN IN
	EXIT

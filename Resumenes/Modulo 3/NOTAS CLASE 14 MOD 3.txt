VIRTUALIZACION:

HOST FISICO / HIPERVISOR / VM GUEST.
TIPO 1: SOBRE HARDWARE.
TIPO 2: SOBRE SISTEMA OPERATIVO ANFITRION.
VNIC: INTERFAZ VIRTUAL / VSWITCH: SWITCH VIRTUAL.
CONTENEDOR: AISLA PROCESOS, NORMALMENTE COMPARTE KERNEL.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

NUBE:

IAAS: COMPUTO / RED / ALMACENAMIENTO.
PAAS: PLATAFORMA PARA EJECUTAR APLICACIONES.
SAAS: APLICACION COMO SERVICIO.
PUBLICA / PRIVADA / HIBRIDA / COMUNITARIA.
VIRTUALIZACION LOCAL NO ES AUTOMATICAMENTE CLOUD.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

PLANOS:

DATOS: REENVIO DE PAQUETES.
CONTROL: DECISIONES Y CONSTRUCCION DE RUTAS.
GESTION: CONFIGURACION Y MONITOREO.
SDN: CONTROL PROGRAMABLE Y COORDINADO.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

APIS Y RED LOGICA:

NORTHBOUND: APLICACION - CONTROLADOR.
SOUTHBOUND: CONTROLADOR - INFRAESTRUCTURA.
UNDERLAY: TRANSPORTE.
OVERLAY: RED LOGICA SOBRE EL TRANSPORTE.
NFV: FUNCION DE RED EN SOFTWARE.
VRF: TABLAS DE ROUTING SEPARADAS.
SPINE-LEAF: LEAF CONECTADOS A CADA SPINE.

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::

INTENCION Y REPASO:

EXPRESAR RESULTADO / TRADUCIR / ACTIVAR / VERIFICAR.
CONTROLADOR LOGICAMENTE CENTRALIZADO PUEDE SER UN CLUSTER.
GESTION CLOUD NO OBLIGA A ENVIAR TODO EL TRAFICO DE USUARIOS A ESA NUBE.
VERIFICAR SIEMPRE EL UNDERLAY ANTES DE CULPAR AL OVERLAY.
